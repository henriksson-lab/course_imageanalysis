# Shared demo libraries (demos/src/lib/)

Import from these files instead of writing a local copy; extend them through their owner (see plan/review-organisation.md, section 3.1). Tests: demos/test/*-test.ts.

## 2D image and numeric libraries

No DOM unless marked. Grey images are `Grey {width, height, data: Float32Array}` (row-major, y down, pixel centres at integers); masks and label images are flat arrays plus `w, h`. Matrices are row-major `Float64Array`s with explicit sizes. Tests: `demos/test/foundation-2d-test.ts`.

- `imageops.ts`: `Grey`, `createGrey`, `fromArray`, `fromFunction`, `cloneGrey`, `mapGrey`, `combine`, `cropGrey`, `stats`, `rescale` · `Border` (zero/replicate/mirror/wrap), `borderIndex`, `pixel`, `sampleNearest`, `sampleBilinear`, `warp`, `resize` (nearest/bilinear/area), `rotate`, `translate` · `correlate2d`, `convolve2d`, `correlateRows/Cols`, `separable` · `gaussianKernel(σ, order 0/1/2)`, `gaussianBlur`, `gaussianDerivative(img, σ, ox, oy)`, `gradient`, `logFilter`, `dogFilter`, `boxFilter`, `sobel`, `laplacian`, `SOBEL_X/Y` · `pyrDown`, `pyrUp`, `gaussianPyramid`, `laplacianPyramid`, `collapsePyramid`, `boxDown2` · display: `DisplayMode` (clip/auto/abs/mid = 0 is mid-grey), `displayRange`, `toBytes`, `toRGBA(img, opts, lut?)`, DOM: `toImageData`, `drawGrey`, `greyCanvas`, `fromImageData`, `loadGrey(url, size?)`.
- `cell.ts` (DOM; imports the PNG, so not usable in node tests): `loadCell(size?)` → the course micrograph `cell256.png` as a Grey 0..255, `CELL_URL`, `CELL_CREDIT` (show it).
- `synth.ts`: seeded generators with ground truth: `nuclei(opts)` (touching, elongated; labels, ellipses, touchingPairs), `discs`, `spots(opts)` (uneven background, Gaussian/Poisson noise; spot list, background, centres), `filaments(opts)` (curves, centreline, mask), `sheppLogan(n)` + `SHEPP_LOGAN` ellipses + `phantomValue`, `checkerboard`, `siemensStar`, `zonePlate`, `ramp`, `stepEdge`, `addGaussianNoise`, `addPoissonNoise`, `rasteriseEllipses`.
- `random.ts`: `rng(seed)` (re-exported from ui.ts), `Rng`, `uniform`, `randInt`, `gauss`, `poisson` (exact, any λ), `exponential`, `bernoulli`, `binomial`, `shuffle`, `permutation`, `sampleIndices`, `choice(weights)`, `normalArray`. Generator first: `gauss(r, mean, sd)`, `poisson(r, λ)`.
- `fft.ts`: `fft1d`, `fft2d` (square), `fft2dRect(re, im, w, h, inv)`, `fft3d`, `dft1d` (any n, reference), `freq`, `nextPow2`, `isPow2`, `padTo`, `crop`, `fftshift`, `ifftshift`, `fftReal2d`, `ifftReal2d`, `magnitude`, `phase`, `logMagnitude`, `complexMul(…, conjB)`, `complexDiv(…, eps)`, `convolveFFT`, `correlateFFT` (circular). `fourier2d/fft.ts` re-exports it.
- `linalg.ts`: `dot`, `norm`, `identity`, `matMul`, `transpose`, `matVec`, `matTVec`, `outer`, `column`, `covariance` · `eigSym2` (closed form, angle), `eig2` (general 2×2, complex pairs), `svd2` (closed form), `det2`, `inv2`, `det3`, `inv3`, `cross3` · `jacobiEigen(A, n, descending?)` · `svd(A, m, n)` (one-sided Jacobi), `pinv`, `lstsq`, `cond`, `rank`, `nullSpace` · `lu`, `luSolve`, `solve`, `inverse`, `det` · `cholesky`, `choleskySolve`, `choleskyLogDet`.
- `histogram.ts`: `Histogram`, `histogram(data, {bins, min, max, weights, mask})`, `intHistogram(data, vmin?, vmax?)` (one bin per integer: negative and 16-bit fine), `binOf`, `binCentre(s)`, `normalise`, `density`, `cumulative`, `histStats`, `histPercentile`, `percentile` (raw data), `mode`, `histogram2d(x, y, {…, circularX})`, `range`.
- `metrics.ts`: image quality `mse`, `rmse`, `mae`, `psnr(a, b, peak)`, `psnrFromMse`, `ssim(a, b, w, h, opts)` → {mean, map} · segmentation `confusion(pred, truth, valid?)` → `Counts`, `dice`, `jaccard`, `precision`, `recall`, `f1`, `specificity`, `fpr`, `accuracy`, `diceMasks`, `jaccardMasks`, `confusionMatrix(pred, truth, k)`, `classCounts`.
- `label.ts`: `Labels`, `UnionFind`, `label2d(mask, w, h, 4|8)`, `label3d(mask, nx, ny, nz, 6|18|26)`, `offsets2d`, `offsets3d`, `componentSizes`, `boundingBoxes`, `centroids`, `relabel`, `removeSmall`, `maskOf`. Labels 1..count in raster order of first pixel.
- `distance.ts`: `edt(mask, w, h, {squared, spacing})` (exact Euclidean, to the nearest background pixel), `edtWithNearest` (+ feature transform), `edt3d`, `chamfer(mask, w, h, "cityblock"|"chessboard"|"3-4"|"5-7-11")`, `signedDistance` (negative inside).
- `morph.ts`: SEs `seDisk`, `seSquare`, `seDiamond`, `seLine`, `seFromMask`, `seReflect`, `seRadius` · grey `erode`, `dilate`, `open`, `close`, `whiteTopHat`, `blackTopHat`, `morphGradient`, `rankFilter`, `median` · binary `erodeBinary`, `dilateBinary`, `openBinary`, `closeBinary`, `hitOrMiss` · `geodesicDilate`, `geodesicErode`, `reconstructByDilation`, `reconstructByErosion` · `regionalMaxima`, `regionalMinima`, `hMaxTransform`, `hMinTransform`, `hMaxima`, `hMinima`, `imposeMinima` · `fillHoles`, `clearBorder`.
- `pqueue.ts`: `PriorityQueue` (int items, numeric keys, FIFO among ties), `Heap<T>(less)`, `BucketQueue(levels)` (integer levels, FIFO per level), `Fifo` (growable int ring).
- `polar.ts`: `PolarOptions {cx, cy, rMax, rMin?, nR, nTheta, log?}`, `toPolar` (columns = angles, rows = radii, bilinear), `fromPolar`, `radiusAt`, `angleAt`, `rowOf`, `colOf`, `radialProfile`.

Rough timings at 256² in node: Gaussian blur σ = 3 ≈ 14 ms, FFT forward + inverse ≈ 19 ms, exact EDT ≈ 26 ms, 8-connected labelling ≈ 4 ms, grey opening with a disk of radius 5 ≈ 55 ms, reconstruction/h-maxima ≈ 65 ms (measure in the browser before promising "live").

## Plotting, UI, colour and WebGL libraries

SVG/canvas components on top of `ui.ts`; colours only through the `--qb-*` variables of `demos/demo.css` (which also holds the components' CSS). Pointer only, never the keyboard (reveal.js keeps the arrow keys); pointer positions via `getBoundingClientRect`/`getScreenCTM`, so they work in scaled slides. Tests: `demos/test/foundation-ui-test.ts`. Check page (not linked): `demos/src/libdemo/` (`data-demo="libdemo"`).

- `plot.ts`: `Plot(parent, {x, y, xlog, ylog, xlabel, ylabel, title, equal, xticks, …})` with marks `line`, `fn`, `step` (post/mid), `band`, `scatter` (per-point colours), `bars`, `histogram(edges, counts)`, `heatmap(values, nx, ny, {map, numbers, …})` (rects, or one image above 4096 cells), `ellipse(mean, cov, nsd)`, `vline`, `hline`, `arrow`, `text`, `legend`; every mark has `set(...)`/`remove()`; `setDomain`, `toData(ev)` · `PolarPlot` (`line`, `scatter`, `ray`, `half` for 0–180°; angles CCW on screen) · `heatmapGrid` (matrix with row/column labels and numbers) · `colorbar` · `seriesColor(i)`, `niceTicks`, `logTicks`, `makeScale`, `extent`, `ellipsePoints`.
- `colour.ts`: `srgbToLinear`, `linearToSrgb`, `SRGB8_TO_LINEAR`, `linearToSrgb8`, `D65`, `M_RGB_TO_XYZ`/`M_XYZ_TO_RGB`, `linearRgbToXyz`, `xyzToLinearRgb`, `luminance`, `xyzToLab`, `labToXyz`, `srgbToLab`, `labToSrgb`, `labInGamut`, `labToLch`, `lchToLab`, `rgbToHsv` (NaN hue for greys), `hsvToRgb`, `deltaE76` · maps `grey`, `viridis`, `inferno`, `diverging` (+ `divergingT`), `COLORMAPS`, `mapFromAnchors` (Lab interpolation), `QUALITATIVE`, `OKABE_ITO`, `categoryColor`, `labelColor`/`labelPalette`/`labelLUT` (0 = background), `lightnessProfile` · `colormapLUT`, `scalarToRGBA`, `scalarToImageData`, `drawScalarImage`, `drawLabelImage`, `hexToRgb`, `rgbToHex`, `toCss`, `textColorOn`.
- `gridui.ts`: `GridView` (cells with numbers; binary/int/float/label display; edit rules toggle, cycle, plus/minus or a function, with drag painting; `show({values, focus, window, marks, arrows})`) · `gridStepper(parent, {rows, cols, initial, algorithms, presets, extraButtons, …})`: main + optional aux grid, reset/back/step/play/end/next-stage, speed, counter, log; an algorithm is a `GridAlgorithm` whose `run()` generates `GridFrame` snapshots · `N4`, `N8`, `CROSS3`, `SQUARE3`, `offsetsFromGrid`, `gridFromText`.
- `paint.ts`: `LabelPainter(parent, {width, height, labels, brush, onChange})` (label buttons, eraser, brush slider, undo per stroke, clear; `setImage`, `setOverlay`, `setLabels`) · `paintSegment` (pure), `labelCounts`.
- `datasets2d.ts` (no DOM): `LPoint`, `Dataset2D`, `blobs`, `anisotropic`, `moons`, `rings`, `xor`, `spirals`, `withOutliers`, `withLabelNoise`, `DATASETS` presets + `dataset(id)`, `toArrays`, `classStats`; re-exports `pointPlayground`.
- `playground.ts`: `pointPlayground(parent, {data, k, presets, onChange, …})` → add/drag/remove points of k classes, `setBackground(probabilities)` / `setBackgroundColour(fn)` decision map, `overlay` group with `sx`/`sy`.
- `shapecanvas.ts`: `shapeCanvas(parent, {size, shapes, presets, onChange})` (draw closed shapes, drag vertices or shapes, rotate/scale/mirror/move buttons, mask shown under the outlines) · pure: `rasterise(polys, w, h, rule)`, `polygonArea`, `polygonCentroid`, `rotatePoly` (CCW on screen), `scalePoly`, `translatePoly`, `mirrorPoly`, `ellipsePoly`, `starPoly`, `SHAPE_PRESETS`.
- `mat4.ts` (no DOM; column-major Float32Array, WebGL conventions): `identity`, `fromRows`, `at`, `multiply`, `mul`, `transpose`, `translation`, `scaling`, `rotationX/Y/Z`, `rotation(axis, angle)`, `perspective`, `ortho`, `lookAt`, `invert`, `normalMatrix` (M^-T, 3×3), `upper3`, `transformPoint`, `transformDir`, `transformVec4`, `mat3Vec`, `formatMat`, vector helpers `add`, `sub`, `scale3`, `dot`, `cross`, `length`, `normalize`.
- `gl3d.ts` (WebGL2): `GLView(parent, {aspect, viewports, background, fallback, onCamera})` with `addMesh` (flat/smooth, unlit/Lambert/Blinn–Phong, wireframe overlay/only, opacity), `addPoints`, `addLines` (thick screen-space lines), `addSlice` (2D texture on a quad), `addVolume` (3D texture; `mip`, `dvr` with a transfer-function LUT, `iso` first hit), several viewports per canvas, `pointerRay(ev)`; context created only while visible and released off-screen; message instead of a canvas without WebGL2 · `OrbitCamera` (`view()`, `projection()`, `orbit`, `zoom`, `setView`), `viewButtons` · geometry `computeVertexNormals`, `cubeMesh`, `sphereMesh`, `heightFieldMesh`, `axesLines`, `boxLines`, `transferLUT`, `webgl2Available`.
